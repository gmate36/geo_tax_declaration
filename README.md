# declare

Подаёт месячную декларацию малого бизнеса (1%) на rs.ge за прошлый месяц.

```
./declare            # валюту, сумму и дату вводишь сам
./declare --garna    # всё берётся из Garna
./declare --dry-run  # заполнить, но не подавать
```

Считает лари по курсу НБГ на дату поступления, заполняет декларацию, подаёт после твоего `y`, скачивает PDF и даёт ссылку на оплату. Файлы - в `~/declarations/ГГГГ-ММ/`.

Нужны macOS, Google Chrome и `python3`. Пароли спрашиваются один раз и хранятся в Связке ключей, код из SMS rs.ge вводишь при каждом запуске. Для Garna раз в полгода откроется окно Chrome под код 2FA.
