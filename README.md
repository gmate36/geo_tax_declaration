# declare

Месячная декларация малого бизнеса (1%) на rs.ge для тех, кому платят через Garna. Одна команда раз в месяц:

```
./declare
```

Что делает:

1. Заходит в Garna, берёт поступления за прошлый месяц и скачивает их инвойсы.
2. Берёт курс НБГ на дату каждого поступления, считает доход в лари с округлением вверх и налог 1%.
3. Заходит на rs.ge (код из SMS вводишь в терминале), открывает декларацию малого бизнеса, включает автозаполнение нарастающего итога, вписывает доход в поле 20.
4. Показывает поля 15, 20 и налог и подаёт только после твоего `y`.
5. Скачивает PDF поданной декларации и выдаёт ссылку на оплату с уже вписанными ID, именем и назначением.

Всё складывается в `~/declarations/ГГГГ-ММ/`.

## Что нужно

- macOS, Google Chrome в `/Applications`.
- `python3`. На чистом маке первый вызов `python3` предложит поставить Command Line Tools - соглашайся.

Системных разрешений скрипт не просит: ни доступа к диску, ни управления компьютером. Chrome работает невидимо, со своим отдельным профилем.

## Первый запуск

Garna не пускает невидимый браузер (reCAPTCHA), поэтому в первый раз скрипт откроет обычное окно Chrome - входишь в Garna руками, с кодом двухфакторной защиты, окно закрывается само. Garna помнит вход примерно полгода, потом окно откроется снова.

Логин и пароль от rs.ge скрипт спросит один раз и положит в Связку ключей (`declare-rs.ge`). Код из SMS rs.ge присылает при каждом запуске.

Сменить пароль rs.ge:

```
security delete-generic-password -s declare-rs.ge
```

## Опции

- `--month 2026-09` - другой месяц вместо прошлого.
- `--dry-run` - всё заполнить и сохранить черновик на rs.ge, но не отправлять.
- `--debug` - сохранять скриншоты шагов в папку месяца.

Курс берётся на дату поступления денег в Garna, округление дохода вверх до целого лари.
