# declare

Месячная декларация малого бизнеса (1%) на rs.ge. Одна команда раз в месяц, за прошлый месяц:

```
./declare            # сумму и дату поступления вводишь сам
./declare --garna    # поступления и инвойсы берутся из Garna
```

Что делает:

1. Берёт поступления за прошлый месяц: спрашивает валюту (1 - USD, 2 - EUR, 3 - GBP или любой трёхбуквенный код), сумму и дату поступления. С `--garna` - находит их сама в долларовом и евровом счёте Garna и скачивает инвойсы.
2. Берёт курс НБГ этой валюты на дату каждого поступления, считает доход в лари с округлением вверх и налог 1%.
3. Заходит на rs.ge (код из SMS вводишь в терминале), открывает декларацию малого бизнеса, включает автозаполнение нарастающего итога, вписывает доход в поле 20.
4. Показывает поля 15, 20 и налог и подаёт только после твоего `y`.
5. Скачивает PDF поданной декларации и выдаёт ссылку на оплату с уже вписанными налоговым номером, именем и назначением.

Всё складывается в `~/declarations/ГГГГ-ММ/`.

## Что нужно

- macOS, Google Chrome в `/Applications`.
- `python3`. На чистом маке первый вызов `python3` предложит поставить Command Line Tools - соглашайся.

Системных разрешений скрипт не просит: ни доступа к диску, ни управления компьютером. Chrome работает невидимо, со своим отдельным профилем.

## Первый запуск

Логин и пароль от rs.ge (и от Garna, если запускаешь с `--garna`) скрипт спросит один раз и положит в Связку ключей (`declare-rs.ge`, `declare-garna`), дальше берёт оттуда. Код из SMS rs.ge присылает при каждом запуске.

Garna не пускает невидимый браузер (reCAPTCHA), поэтому вход в неё идёт в обычном окне Chrome: скрипт сам вписывает почту и пароль, ты вводишь только код двухфакторной защиты, окно закрывается само. Garna помнит вход примерно полгода, потом окно откроется снова.

Сменить пароль:

```
security delete-generic-password -s declare-rs.ge
security delete-generic-password -s declare-garna
```

## Опции

- `--garna` - поступления из Garna вместо ввода руками.
- `--dry-run` - всё заполнить и сохранить черновик на rs.ge, но не отправлять.
- `--debug` - сохранять скриншоты шагов в папку месяца.

Курс берётся на дату поступления денег, округление дохода вверх до целого лари.
